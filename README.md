# CabinetCompass

CabinetCompass is a cloud-based, database-driven framework utilizing real-time data auto-scaling capabilities to manage infrastructure with a central Agent.

CabinetCompass is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CabinetCompass.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CabinetCompass, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
